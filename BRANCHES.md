# Branches

TandemKit moves with faBolus and faBolusGarmin. The branch and the tags are described once, in faBolus's
[`BRANCHES.md`](https://github.com/faBolus-app/faBolus/blob/main/BRANCHES.md).

In short: `main` is the only branch. Releases are `vX.Y.Z` tags, and faBolus pins one (`v0.6.0`, the
library the rebuilt app uses). `v1-final` tags the library as the earlier app used it, and `archive/*`
tags keep the deleted side branches.
